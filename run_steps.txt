1. Create project folder:
   enterprise_doc_intelligence

2. Create virtual environment:
   python -m venv venv

3. Activate venv:
   Windows:
   venv\Scripts\activate

4. Install dependencies:
   pip install -r requirements.txt

5. Create .env file:
   Copy .env.example to .env
   Add your API key(s)

6. Run app:
   streamlit run app.py
